Preguntas frecuentes

¿Esta landing corresponde a una versión publicada de la APK?

No. Es un prototipo web académico independiente que utiliza el nombre TechAtlas UPTC como concepto de presentación.

¿Se puede consultar desde un celular?

La estructura HTML y CSS fue desarrollada con un diseño adaptable. La prueba visual final debe realizarse en dispositivos y resoluciones solicitadas.

¿Qué ocurre con los datos del formulario?

Se conservan temporalmente en el navegador hasta el envío; un servicio externo requiere configurar un endpoint propio y obtener consentimiento.

Conoce el proyecto

Formulario de interés para demostración de persistencia. Los datos se conservan en este navegador hasta que se envían correctamente o se eliminan.

Las solicitudes se envían mediante Formspree. Recibirás una confirmación cuando el servicio acepte el envío.

No ingreses contraseñas, documentos de identidad ni información sensible. localStorage es accesible desde este navegador.
